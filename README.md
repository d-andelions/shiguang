# 拾光校园 · 校园闲置资源共享平台 MVP

工程管理课程项目（19 组）"校园闲置资源共享平台建设与试运行管理"的**单校区轻量化网页 MVP** 实现。

技术栈：Python 3 / Flask / SQLite / 原生 HTML+CSS+JS（零前端构建步骤，部署即用）。

## 课程汇报要求 → MVP 覆盖对照

| 课程汇报要点 | 本 MVP 实现 |
|---|---|
| 物品发布 | `/publish`：标题、分类、成色、交易方式（出售/免费赠送/交换）、价格、校区、描述、图片上传（≤5MB，白名单格式） |
| 分类搜索 | 首页关键词（标题+描述模糊搜索）+ 分类/校区/交易方式/状态四维筛选 + 最新/价格排序；默认只展示「在售」，缓解"已转出物品仍被反复询问"痛点 |
| 详情查看 | `/item/<id>`：完整物品信息 + 联系发布者 |
| 状态更新 | 在售 / 已转出 / 已下架，详情页与"我的发布"均可一键更新 |
| 数据持久化 | SQLite（`instance/shiguang.db`）+ 图片落盘（`uploads/`），刷新/换设备数据一致 |
| 权限控制 | 注册/登录（werkzeug 密码哈希 + Session）；**服务端归属校验：本人可编辑、他人不可改（他人操作返回 403）** |
| 隐私顾虑缓解 | 联系方式仅登录用户可见，未登录显示"登录后可查看" |
| 首批物品品类 | 教材 / 数码配件 / 生活用品（另设"其他"兜底） |
| 试点校区 | 江湾校区（含邯郸/枫林/张江选项） |
| 建设边界（不做） | 在线支付、物流配送、复杂站内聊天、信用评分、自动仲裁、EXIF 真实性判定 |

最小功能闭环：**发布 → 搜索/筛选 → 查看详情 → 联系发布者 → 更新状态**

## 快速开始

```bash
cd shiguang-mvp
python3 -m pip install -r requirements.txt   # 仅 flask
python3 seed.py                              # 重置数据库 + 演示数据（可选但推荐）
python3 app.py                               # 启动，默认 0.0.0.0:5000
```

浏览器打开 `http://localhost:5000`。同一校园网/内网下可用手机访问 `http://<服务器IP>:5000`，验证"跨设备数据一致"（端口可用环境变量 `PORT` 覆盖）。

## 演示账号与验收用例

演示账号：`demo1 / shiguang123`、`demo2 / shiguang123`（对应课程 W6"双账号测试"）：

1. **发布**：demo1 登录 → 发布物品（含图片）→ 跳转详情页。
2. **搜索**：首页按关键词"教材"搜索、按分类/校区/状态筛选、按价格排序。
3. **他人不可改**：demo2 登录后打开 demo1 的物品详情——看不到编辑/删除/状态按钮；直接请求 `/item/<id>/edit`、`/item/<id>/status` 返回 **403**。
4. **本人可改**：demo1 将物品状态改为「已转出」→ 首页默认列表不再显示，筛选"已转出"可见。
5. **数据一致**：换浏览器/手机再开详情页，状态与图片保持一致（SQLite 持久化）。
6. **隐私**：未登录打开详情页，联系方式显示"🔒 登录后可查看"。
7. **失败场景**：非图片格式/超 5MB 图片被拒并提示；未登录发布被引导至登录页。

## 目录结构

```
shiguang-mvp/
├── app.py               # Flask 应用：路由、鉴权、物品 CRUD、图片上传
├── db.py                # SQLite 连接与建表（instance/shiguang.db）
├── seed.py              # 重置并写入演示数据 + SVG 占位图
├── requirements.txt
├── templates/           # Jinja2 页面（列表/详情/发布/编辑/登录/注册/我的发布）
├── static/style.css
├── uploads/             # 物品图片（seed-xx.svg 为演示占位图）
└── instance/shiguang.db # SQLite 数据库（运行后生成）
```

## 已知简化与后续迭代（对应课程"风险与边界"）

- **安全**：Session Cookie 未加 CSRF Token；建议正式试用前接入（课程内网演示风险可控）。
- **图片**：未做 EXIF 隐私信息清洗与真实性判定（课程汇报已明确不做该承诺）。
- **容量**：列表上限 100 条、单图 ≤5MB，适合单校区试点规模；扩展需分页与对象存储。
- **运营**：无管理员审核后台；试点期信息质量靠"实物图、成色/校区、上下架状态复核"的人工流程（见汇报 W7–8 招募与核验）。
- **责任边界**：平台仅提供信息流转，不介入交易、支付与纠纷（页脚已声明）。
